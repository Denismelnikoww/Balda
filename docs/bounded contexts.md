### Identity & Credentials (аккаунты и доступ)

События: ПользовательЗарегистрирован, ПровайдерПодключён, МандатВыдан, МандатОтозван.  
Глоссарий:
- Владелец (Owner) - аккаунт пользователя «ГонятьБалду»; субъект, от чьего имени действует система.
- Связка (Connection) - привязка владельца к внешнему провайдеру с набором разрешений.
- Мандат (Credential/Mandate) - действующий OAuth-токен (+ scopes, срок жизни) для связки.
- Scope - разрешённый набор операций мандата во внешнем сервисе.
- Отзыв (Revocation) - событие, после которого мандат нельзя использовать.

### Behavior Profile (профиль поведения)

События: ПрофильПоведенияСоздан, ПрофильПоведенияОбновлён, ПаттернАктивностиЗафиксирован.  
Глоссарий:
- Профиль поведения - модель типичного поведения владельца (рабочие часы, частота, стиль).
- Паттерн активности - устойчивая наблюдаемая закономерность (например, «пик коммитов 10:00–12:00»).
- Стиль - предпочтения формулировок (тон сообщений в WK Teams, формат коммитов).

### Campaign/Plan (планирование и политика)

События: НамерениеСформулировано, ПланАктивностиСоздан/Скорректирован/Запущен/Приостановлен/Отменён, ШагПланаЗапланирован, ШагПланаНазначенНаВремя.  
Глоссарий:
- Намерение (Intent) - сформулированная пользователем цель («работаю над X в выходные»).
- План активности (Activity Plan) - связная серия шагов во времени с ограничениями (окна, паузы, причинность).
- Шаг плана (Plan Step) - одно будущее действие в плане (что, где, когда).
- Политика правдоподобия (Policy) - правила плана: рабочие часы, паузы, причинная связность, интенсивность.
- Сага плана (Plan Saga) - оркестрация исполнения шагов с retry и компенсациями.
    

### Delivery (интеграции/ACL)

События: ДействиеЗапрошеноКИсполнению, ДействиеВыполнено, ДействиеПроваленоОшибкой, ДействиеПовтореноЗапросом, ДействиеКомпенсировано, КоммитСоздан, СообщениеОтправлено, СтатусИзменён, ТикетОбновлён, ПисьмоОтправлено, ОтветAPIПолучен, ОшибкаAPIПолучена.  
Глоссарий:
- Действие (Action) - единица исполнения во внешнем сервисе (commit / message / ticket_update / email).  Имеет `actionId`
- Адаптер (ACL) - антикоррупционный слой под конкретный провайдер (Git-провайдер, WK Teams, Ledmine, SMTP), переводящий Действие в вызовы API.
- Внешняя ссылка (ExternalRef) - идентификатор результата (sha коммита, ts сообщения в WK Teams); Plan его не парсит.
- Идемпотентность действия - гарантия, что повтор по `actionId` не создаёт дубль.

### Billing & Notifications (подписка и уведомления)

События: ПодпискаОформлена, ОплатаПрошла, ОплатаНеУдалась, УведомлениеОтправлено.  
Глоссарий:
- Подписка - право владельца пользоваться сервисом на период.
- Платёж - попытка списания через платёжный шлюз с результатом.
- Уведомление - сообщение владельцу (email через почтовый провайдер) о событиях (оплата, инцидент).
- Тариф - набор лимитов (число планов, провайдеров, действий).
